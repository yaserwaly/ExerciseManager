\# ExerciseManager



A personal C++ console tool for managing coding exercises across a series

of courses inside a single project, instead of one project per exercise.



> Status: under development. Windows + Visual Studio 2026 only.



\## Concept



\- Add, rename, and delete exercises (each with a name and description)

\- Automatic exercise numbering

\- An exercise is built and run only when you select it



\## Privacy



Your courses, exercises, and shared libraries live in a separate personal

workspace and are never part of this repository.



\## Requirements



\- Windows

\- Visual Studio 2026 (C++20, `/std:c++20`)
